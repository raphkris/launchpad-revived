## 1. Scope warning — this delta writes drag code, and must stop short

`LAY-09` requires drag handling on the background. `INT-03` (drag an icon to reorder) and `INT-04` (drag to an edge to turn the page) are **Slice 2** and stay unimplemented. Dragging *an icon* must do nothing in this slice. Build the background drag recognizer so that it does not become icon-drag infrastructure by accident.

## 2. Amendments to existing requirements

| ID | | Amendment |
|---|---|---|
| `LAY-04` | `[D]` | **Amended.** The page indicator is dots only, with **no background surface** — no glass capsule, no `GlassEffectContainer`, no padded container behind them. The dots sit directly on the wallpaper. (`PRJ-05` still governs glass surfaces elsewhere; the point is that this element has no surface at all.) Note: `PageTabViewStyle` / `PageIndexViewStyle` and their `backgroundDisplayMode` are unavailable on macOS — do not reach for a `TabView` to satisfy this. |
| `LAY-05` | `[D]` | **Amended.** Page navigation is via `⌘←` / `⌘→` and by clicking a page dot. Bare `←` / `→` no longer turn pages; they are reassigned to focus movement by `LAY-08`. |
| `LAY-06` | `[D]` | **Promoted from `[O]`.** Horizontal two-finger trackpad scroll **and** mouse scroll wheel turn pages. Both arrive on the same `NSEvent` `.scrollWheel` path — one implementation, not two. Accumulate `scrollingDeltaX`; commit a single page turn once the accumulation passes a threshold, then ignore the remainder of that gesture including its momentum phase, so one flick moves exactly one page. Vertical delta is ignored. |

## 3. New requirements

### 3.1 Keyboard focus

| ID | | Requirement |
|---|---|---|
| `LAY-08` | `[D]` | **Arrow keys move focus between icons.** Focus is a single optional cell index scoped to the current page. Rules: (a) On open, nothing is focused. (b) From no focus, `→` or `↓` focuses the **first cell** of the current page (top-left); `←` or `↑` focuses the **last populated cell** of the current page — on a partially filled page this is the last real app, not the empty bottom-right slot. (c) With focus, `←`/`→` move one cell in reading order, `↑`/`↓` move one row. (d) Movement **clamps** at the page's edges: it does not wrap and does not cross pages. (e) Focus never lands on an empty cell; movement into the empty tail of a partial page clamps to the last populated cell. (f) `⏎` or `Space` launches the focused app per `INT-01`. (g) Any page change — `LAY-05`, `LAY-06`, `LAY-09` — clears focus. |
| `LAY-11` | `[D]` | **`⎋` clears focus if a cell is focused; otherwise it dismisses Launchpad** (`WIN-11`). This mirrors the shape of `SRC-08`. This is the one behavior in this delta that requires editing a file outside this delta's ownership — see §5. |
| `LAY-12` | `[D]` | **The focus indicator is visually distinct from hover.** A focused cell and a moused-over cell must not look the same. Use system focus styling; per `PRJ-05`, do not hand-roll a glow or blur imitation. |
| `LAY-13` | `[O]` | Whether arrow-key focus should cross page boundaries — i.e. `→` on the last cell of a page turning to the next page and focusing its first cell. Deferred deliberately; `LAY-08(d)` clamps for now. Does not block this slice. |

### 3.2 Pointer

| ID | | Requirement |
|---|---|---|
| `LAY-09` | `[D]` | **Click-drag on the background turns pages.** Press on background (as defined by `LAY-10`) and drag horizontally: page content tracks the cursor 1:1, rubber-banded at the first and last page. On release, commit to the adjacent page if horizontal displacement is at least 25% of the page width *or* release velocity exceeds a flick threshold; otherwise spring back to the current page. Vertical displacement is ignored. A press-and-release whose total displacement stays under ~5 pt is a click, not a drag, and dismisses per `WIN-11`. |
| `LAY-10` | `[D]` | **A cell's interactive region is the icon rect plus its label rect — not the full cell rect.** Currently `AppIconView`'s button label fills the whole cell, so the empty space beneath a short label launches the app. Everything inside a cell that is not icon-or-label counts as **background** for `WIN-11` (click to dismiss) and `LAY-09` (drag to paginate). |

## 5. File ownership

Ownership is exclusive and binding.

**Owned by this delta — edit freely:**

- `LaunchpadRevived/AppGridView.swift`
- `LaunchpadRevived/PageIndicatorView.swift`
- `LaunchpadRevived/AppIconView.swift`
- `LaunchpadRevived/GridLayout.swift`
- `LaunchpadRevived/LaunchpadRootView.swift`
- `LaunchpadRevived/LaunchpadViewModel.swift`
- New files as needed (`PRJ-09`: one primary type per file, ≤ 300 lines)

**Out of scope — do not edit, and do not change behavior that lives in them:**

- `AppDelegate.swift`, `LaunchpadWindow.swift`, `WindowResignDelegate.swift`, `PresentationOptionsGuard.swift`, `Info.plist`

If satisfying a requirement in this delta appears to require touching one of those files, stop and say so rather than editing it.

**Known seam — the one permitted exception.** `LAY-11` requires a single narrow edit to `LaunchpadSessionController.swift`: the Escape handler must consult focus state before dismissing. Make it one guard that calls into the view model, and change nothing else in that file. In particular, `present`, `dismiss`, and the existing cases in the `NSEvent` key monitor are out of scope — leave them exactly as you find them.

All arrow-key and `⌘`-arrow handling introduced by this delta belongs in the SwiftUI layer (`.onKeyPress` / `.focusable`), **not** in the `NSEvent` monitor.

## 6. Done when

- The page dots render with no capsule or surface behind them.
- Two-finger horizontal trackpad scroll turns exactly one page per flick; a mouse scroll wheel does the same.
- Click-dragging empty space moves the page under the cursor and commits or springs back on release; a plain click on empty space still dismisses.
- Clicking the dead space below a short app label does nothing instead of launching that app.
- From a fresh open, `→` focuses the top-left icon and `←` focuses the last populated icon; arrows then move focus without wrapping or leaving the page; `⏎` launches the focused app.
- A focused icon looks different from a hovered one.
- `⌘←` / `⌘→` turn pages and clear focus.
- `⎋` clears focus when something is focused, and dismisses when nothing is.
- No icon reordering exists — dragging an icon does nothing (`INT-03` is Slice 2).
- `./run.sh --build` succeeds and `swift-format` has been run.
